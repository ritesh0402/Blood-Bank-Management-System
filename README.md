# Blood-Bank-Management-System
Blood bank management system using Java Swing and MySQL
## Introduction

Blood-Bank-Management-System is a Java-based application that allows for efficient management of a blood bank. It utilizes Java Swing for its user interface and MySQL for its database management. This project was created by ritesh0402 and is available on GitHub for others to use and contribute to.

As the name suggests, the purpose of this project is to assist blood banks in managing their inventory and donations. It keeps track of available blood types, donors, and recipients, making it easier for blood banks to fulfill requests and maintain a healthy supply of blood.

## Features

- Easy and user-friendly interface for efficient data entry and retrieval
- Ability to add and update blood donation records
- Tracking of donor information, including name, contact information, and blood type
- Record of recipient information and blood type required
- Automatic notification system for low blood supply or urgent requests
- Data backup and retrieval options

## Installation

**Requirements:**
- Java SE Development Kit
- Java Swing GUI library
- MySQL database management system

**Steps:**
1. Clone or download the repository from https://github.com/ritesh0402/Blood-Bank-Management-System.
2. Install Java and Java Swing libraries on your local machine.
3. Install MySQL database management system on your local machine.
4. Create a new database named "blood_bank" on MySQL.
5. Import the .sql file from the repository into the "blood_bank" database.
6. Open the project in your Java IDE.
7. Edit the database connection settings in the "Database.java" file to match your local MySQL database settings.
8. Run the project.
